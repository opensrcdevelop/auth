# Combined Workflow:
用户勾选了 N 个子项，其中 M 个要批准，其余 (N-M) 个要拒绝。

**流程：**
1. 用户勾选需要操作的子项
2. 用户点击「批准选中」或「拒绝选中」
3. 如果两者都想操作：先批准选中的，再拒绝未选中的（或其他顺序）
4. 或者：用户分两次操作——先批准部分，再拒绝部分

**注意：** 当前实现中，用户需要分两次提交：
1. 第一次：批准勾选的子项（调用 approveRequest）
2. 第二次：拒绝剩余的子项（调用 rejectRequest）

这符合 D-23 的描述"通过勾选子项 + 一次提交实现"——一次提交只能做一个操作（批准或拒绝），但可以通过两次提交实现部分批准+部分拒绝。
</context>

**新增 computed 和方法（添加到 index.ts）：**

```typescript
// 待处理的子项数量
const pendingItemCount = computed(() => {
  return requestDetail.value?.items?.filter((item: any) => item.status === 'PENDING').length ?? 0;
});

// 批准其余未选中的待处理项
const handleApproveRemaining = () => {
  const remainingIds = requestDetail.value?.items
    ?.filter((item: any) => item.status === 'PENDING' && !selectedItemIds.value.includes(item.itemId))
    ?.map((item: any) => item.itemId) ?? [];

  if (remainingIds.length === 0) {
    Message.warning('没有其余需要批准的权限');
    return;
  }

  // 设置为批准其余的项
  approveForm.itemIds = remainingIds;
  approveForm.expressionIds = [];
  approveForm.priority = undefined;
  loadExpressionList();
  approveModalVisible.value = true;
};

// 拒绝其余未选中的待处理项
const handleRejectRemaining = () => {
  const remainingIds = requestDetail.value?.items
    ?.filter((item: any) => item.status === 'PENDING' && !selectedItemIds.value.includes(item.itemId))
    ?.map((item: any) => item.itemId) ?? [];

  if (remainingIds.length === 0) {
    Message.warning('没有其余需要拒绝的权限');
    return;
  }

  // 设置为拒绝其余的项
  rejectForm.itemIds = remainingIds;
  rejectForm.rejectReason = '';
  rejectModalVisible.value = true;
};
```

```typescript
// 刷新详情（操作成功后调用）
const handleRefreshDetail = async () => {
  if (requestDetail.value?.requestId) {
    detailLoading.value = true;
    try {
      const res = await getRequestDetail(requestDetail.value.requestId);
      if (res.data) {
        requestDetail.value = res.data;
        // 清空选择
        selectedItemIds.value = [];
      }
    } catch (err) {
      console.error('刷新详情失败', err);
    } finally {
      detailLoading.value = false;
    }
  }
};
```
