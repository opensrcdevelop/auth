</objective>

  <files>ai-chatbi/src/main/java/cn/opensrcdevelop/ai/service/impl/SampleSqlVectorStoreServiceImpl.java</files>
  <action>
    在 `SampleSqlVectorStoreServiceImpl` 类上添加 `@ConditionalOnProperty` 注解：

    1. 添加 import 语句：`import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;`

    2. 修改类注解，将 `@Service` 改为组合注解：
       ```java
       @Slf4j
       @Service
       @ConditionalOnProperty(name = "vectorstore.type", havingValue = "milvus", matchIfMissing = true)
       @RequiredArgsConstructor
       ```

    - `matchIfMissing = true` 确保当配置文件中没有 `vectorstore.type` 属性时，默认激活 Milvus 实现（向后兼容）
    - `havingValue = "milvus"` 确保只有当配置值为 "milvus" 时此 Bean 才会被创建
  </action>
  <verify>
    <automated>
      grep -n "ConditionalOnProperty.*vectorstore.type.*milvus.*matchIfMissing" ai-chatbi/src/main/java/cn/opensrcdevelop/ai/service/impl/SampleSqlVectorStoreServiceImpl.java
    </automated>
  </verify>
  <done>SampleSqlVectorStoreServiceImpl 类上添加了 @ConditionalOnProperty(name = "vectorstore.type", havingValue = "milvus", matchIfMissing = true)</done>
