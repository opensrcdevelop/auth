**3. 创建 PermissionAutoApproveServiceImpl.java（实现）**

查询逻辑：用 LambdaQueryWrapper 按 permissionId 查询 t_permission_auto_approve，若记录存在且 enabled=true 则返回 true，否则返回 false。

```java
package cn.opensrcdevelop.auth.biz.service.permission.request.impl;

import cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionAutoApprove;
import cn.opensrcdevelop.auth.biz.mapper.permission.request.PermissionAutoApproveMapper;
import cn.opensrcdevelop.auth.biz.service.permission.request.PermissionAutoApproveService;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
public class PermissionAutoApproveServiceImpl implements PermissionAutoApproveService {

    private final PermissionAutoApproveMapper permissionAutoApproveMapper;

    @Override
    public boolean isEnabled(String permissionId) {
        LambdaQueryWrapper<PermissionAutoApprove> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(PermissionAutoApprove::getPermissionId, permissionId)
                .eq(PermissionAutoApprove::getEnabled, Boolean.TRUE);
        return permissionAutoApproveMapper.selectCount(wrapper) > 0;
    }
}
```

注意：`@RequiredArgsConstructor` 会自动为所有 `final` 字段生成构造器，添加新的 `final` 字段后注入会自动生效，但需要同步更新 `PermissionRequestRepositoryTest` 中的 `new PermissionRequestRepositoryImpl(permissionRequestMapper)` 为 `new PermissionRequestRepositoryImpl(permissionRequestMapper, permissionRequestItemMapper)`（在 Task 2 末尾处理测试文件）。

实现方法：

```java
    @Override
    public boolean hasActivePendingRequest(String userId, java.util.List<String> permissionIds) {
        // 步骤 1：查询该用户所有 PENDING 或 AUTO_APPROVED 状态的申请ID
        LambdaQueryWrapper<cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequest> requestWrapper =
                new LambdaQueryWrapper<>();
        requestWrapper.eq(cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequest::getUserId, userId)
                .in(cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequest::getStatus,
                        java.util.List.of(
                                cn.opensrcdevelop.auth.biz.constants.PermissionRequestStatusEnum.PENDING.getCode(),
                                cn.opensrcdevelop.auth.biz.constants.PermissionRequestStatusEnum.AUTO_APPROVED.getCode()));
        java.util.List<String> activeRequestIds = permissionRequestMapper.selectList(requestWrapper)
                .stream()
                .map(cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequest::getRequestId)
                .toList();

        if (activeRequestIds.isEmpty()) {
            return false;
        }

        // 步骤 2：检查这些申请中是否包含待检查的权限
        LambdaQueryWrapper<cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequestItem> itemWrapper =
                new LambdaQueryWrapper<>();
        itemWrapper.in(
                cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequestItem::getRequestId,
                activeRequestIds)
                .in(cn.opensrcdevelop.auth.biz.entity.permission.request.PermissionRequestItem::getPermissionId,
                        permissionIds);
        return permissionRequestItemMapper.selectCount(itemWrapper) > 0;
    }
```

**重要**：在 `hasActivePendingRequest` 方法中使用的类引用应改为 import 形式。在文件顶部 import 区域新增：
